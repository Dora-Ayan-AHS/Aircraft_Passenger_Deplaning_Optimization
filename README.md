# Aircraft Passenger Deplaning Optimization

Hi! I'm Dora Ayan, an Industrial Engineering student at Georgia Tech.

I created this project while learning Python and experimenting with simple optimization ideas. Before this, I developed a similar project focused on helping passengers leave a bus more efficiently. This time, I applied the same concept to aviation.

The goal of this project is to explore a practical question:

**How can passengers leave a plane faster?**

Using a simple simulation, I compare different deplaning strategies and analyze their impact on total passenger exit time. While this is a beginner-level project, it combines my interests in process improvement, and industrial engineering.
